# 智能穿戴设备（模拟）全流程采集与元数据质检系统

## 📌 项目简介 (Introduction)
本项目基于**养老服务与物联网**的真实业务场景，使用 Python 模拟智能无感记录仪（可穿戴设备）的数据采集全过程。
项目涵盖了从**设备硬件状态监控**、**元数据记录**、**数据初步质检**，到**异常反馈日志生成**与**可视化报告输出**的完整闭环。旨在验证数据采集方案的可行性，并为下游算法团队提供高质量、可直接用于模型训练的清洗数据集。

## ✨ 核心功能与亮点 (Features)
*   **全维度设备状态监控**：在采集过程中实时模拟并记录设备的**电量状态、存储空间、佩戴位置、时间同步状态**，确保采集前置条件合规。
*   **完整元数据标签化**：精准记录**人员编号、设备编号、动作类型（静止/步行/跌倒）、起止时间、场景信息（卧室/客厅/户外）**，保障数据的可追溯性。
*   **多维度异常排查与清洗**：利用 Pandas 编写质检脚本，自动化识别并处理：
    *   **佩戴脱落**导致的全0无效数据
    *   **低电量**导致的采集中断风险
    *   **时间未同步**导致的时间戳漂移/重复
    *   **信号不稳定**导致的数据缺失 (NaN)
*   **标准化的成果输出**：自动生成《采集异常反馈日志.xlsx》和《数据采集与质量总结报告》，形成闭环的问题反馈机制。

## 🛠️ 技术栈 (Tech Stack)
*   **编程语言**：Python 3.x
*   **数据处理**：Pandas, NumPy
*   **数据可视化**：Matplotlib
*   **办公工具**：Excel（用于数据透视表分析与基础校验）
*   **版本控制**：Git
